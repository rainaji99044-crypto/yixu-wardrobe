# 衣序 YIXU WARDROBE · 第一阶段

衣序是一套无需注册、本地优先的个人衣橱整理工具。第一阶段只完成产品导航、衣橱页面与本地衣物数据保存。

## 当前范围

- 桌面端左侧导航，可折叠；手机端固定四 Tab 导航。
- “衣橱”完整可用。
- “穿搭 / 灵感 / 看板”为明确的后续阶段占位页，没有虚构数据或假功能。
- 衣物支持图片、名称、类别、颜色、多季节、风格文字、品牌、购买信息和备注。
- 支持搜索、季节多选 OR 筛选、分类筛选和四种排序。
- 支持详情、编辑、删除确认、收藏和用户主动记录穿着。
- IndexedDB 保存衣物资料与图片 Blob，刷新或关闭浏览器后仍保留。
- 提供基础 PWA Manifest、Service Worker 和应用图标。

当前版本不包含 AI 去背景、AI 识别、搭配建议、虚拟试穿、账号、云同步或完整统计。

## 本地运行

需要 Node.js 22.13 或更高版本。

```powershell
npm install
npm run dev
```

打开终端显示的本地地址，默认是 `http://localhost:5173/`。

生产检查与构建：

```powershell
npx tsc --noEmit
npm run build
```

构建输出位于 `dist/client`。

## 数据说明

- IndexedDB 数据库：`yixu-wardrobe-v2`。
- 衣物照片会在浏览器内压缩为 WebP Blob，不存入 localStorage。
- 没有任何内置示例衣物。
- 清除浏览器站点数据会删除衣橱；数据设置中保留了本地导出和导入入口。

# 衣序 YIXU WARDROBE

一套本地优先的电子衣橱 PWA。衣物、穿搭、灵感与月度复盘都保存在当前设备的浏览器数据库中；照片会在设备端压缩，不需要登录，也不依赖 GPT、VPN、天气服务或云端数据库。

## 已实现

- 衣物：照片、名称、分类、颜色、季节、风格、状态、品牌、价格与备注；支持检索、筛选、编辑和关联删除。
- 穿搭实验室：选择真实衣物组成穿搭，记录场景、天气文字、日期、评分、舒适度、反馈与上身照片。
- 审美研究室：保存灵感图、来源、标签、配色和结构化分析，并标记是否已实践。
- 衣橱报告：按本机真实数据计算分类、颜色、穿着频率、闲置单品、组合次数、风格与月度复盘。
- 数据安全：完整 JSON 备份、恢复和清空；图片也会包含在备份里。
- PWA：可安装到手机主屏幕；首次在线打开并缓存后，可离线启动和使用。

## 手机上安装

### iPhone / iPad

1. 用 Safari 打开已发布的网址。
2. 点底部“分享”。
3. 选择“添加到主屏幕”，再点“添加”。
4. 从主屏幕打开衣序。首次完整打开后，断网也能继续使用。

### Android

1. 用 Chrome 打开已发布的网址。
2. 点右上角菜单，选择“安装应用”或“添加到主屏幕”。
3. 确认安装，从桌面图标打开。

每台设备的数据互相独立。换手机或清理浏览器前，请在“数据与设置”里导出备份；在新设备中选择“导入备份”即可恢复。

## 本地运行

需要 Node.js 22.13 或更高版本。

```powershell
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。

生产构建：

```powershell
npm run build
```

静态网页位于 `dist/client`，可以部署到任何支持 HTTPS 的静态网站空间。HTTPS 是手机安装 PWA 和离线缓存的必要条件（本机 localhost 调试除外）。

## 数据与隐私

- IndexedDB 数据库名：`yixu-wardrobe-db`。
- 不会自动上传照片或衣橱资料。
- 删除浏览器站点数据会同时删除本地衣橱数据。
- 自动分类或自动抠图若没有真实的本地模型支持，不会伪装成已识别结果；当前版本保留人工确认字段。
